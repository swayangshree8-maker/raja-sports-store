# PlayTrade Sports Gear

A responsive static website for browsing, buying, and listing sports products.

The catalog is limited to shoes, boots, bats, footballs, badminton gear, T-shirts, jerseys, Technosport products, and trophies. Product names, descriptions, and prices currently shown are sample data; replace them with the shop's real stock before taking orders.

## Open locally

Open `index.html` in a browser. The bag and listings are saved in that browser only. Checkout is a preview and does not process payments.

## Publish with GitHub Pages

This site needs no build step. The workflow in `.github/workflows/pages.yml` deploys the site when code is pushed to `main`. In the repository's **Settings → Pages**, set the publishing source to **GitHub Actions**. GitHub will show the published address in the Pages settings after the first successful deployment.
